Hint Effects (TRUE / LIE)

A player may place one hint per turn on their own board. The attacker can guess if that hint is TRUE or a LIE. Effects depend on the real truth and the attacker's guess.

Real hint Attacker guess Effect
TRUE TRUE No effect.
TRUE LIE Defender revives about half of destroyed non-ship cells (rounded).
LIE TRUE Defender gains 2 bonus shots next turn.
LIE LIE A forced correct hint is added for the defender.
Introduction & Game Flow

Battleship Bluff is a pass-and-play game for two players. You place fleets, attack hidden targets, and add bluff hints that can change the next turns.

  1. Setup: each player places ships (length 5, 4, 3, 3, 2), then locks in and passes.
  2. Turn start: current player receives base shots (plus any bonus).
  3. Optional hint: before the first shot, reveal your own board and place one hint card.
  4. Attack: choose a target cell on the opponent board.
  5. If an incoming hint is active, attacker guesses TRUE or LIE, confirms, then effects are applied.
  6. Shot resolves as hit or miss. Hits can grant extra shots if enabled.
  7. When shots end, pass device to the next player.
  8. Game ends when one side sinks all enemy ships, or if someone ends the game.
